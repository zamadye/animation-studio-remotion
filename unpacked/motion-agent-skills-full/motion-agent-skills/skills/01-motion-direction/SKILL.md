# Motion Direction

## Procedure
1. Write one-sentence communication goal for each shot.
2. Establish hierarchy: focal subject > supporting text > background decoration.
3. Select visual metaphor only if semantically defensible; scientific analogies must state limitations.
4. Allocate shot timing using VO word boundaries, semantic pauses and beats. Never force a cut in the middle of a key phrase.
5. For each shot specify: start/end seconds, subject, layout, entrance, hold, exit, easing, sound cue, transition and reframe anchor.
6. Enforce breathing room: a visual needs a readable hold; do not animate every object simultaneously.

## Motion vocabulary
Reveal, build, trace, track, mask, wipe, morph, orbit, parallax, rack focus, split, stack, kinetic type, data count-up, diagram progression, callout, match cut, zoom, depth push, loop.

## Anti-patterns
Random zooms; constant shakes; excessive glow; arbitrary spring bounce; hard-to-read kinetic typography; fake data; effects that conceal information; unmotivated transitions.

## Acceptance
Viewer can identify the primary claim in each scene from a still frame and can follow its temporal change without narration.
