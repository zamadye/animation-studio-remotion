# Modern Motion Template Catalog — 32 production concepts

These are design patterns to implement, NOT claims of downloadable ready-made files. Each entry should be parameterized and tested.

## Typography & editorial
01. Kinetic headline — phrase-by-phrase emphasis, mask reveal
02. Editorial lower third — speaker ID with restrained slide/fade
03. Breaking-news opener — urgent information hierarchy without strobing
04. Pull quote — large quote, source attribution, subtle parallax
05. Chapter bumper — chapter index, wipe, typography grid
06. Typewriter terminal — monospace text reveal, cursor synced to VO
07. Word spotlight — one keyword isolated by contrast/scale
08. Split argument — thesis vs counterargument two-column reveal

## Data, science & explainers
09. Animated bar ranking — value-driven ordering with stable labels
10. Line chart story — axis first, path draw, annotated inflection
11. Network graph — nodes/edges with causal highlighting
12. Timeline of events — date markers, source cards and progress
13. Flowchart — process stages, branch decisions and connectors
14. Formula breakdown — variable labels, substitutions, result emphasis
15. Comparison matrix — alternatives and trade-offs, responsive rows
16. System layers — exploded diagram and focus isolation

## Documentary & storytelling
17. Evidence board — documents, pin connectors, controlled camera moves
18. CCTV reconstruction — timestamp and framing with provenance label
19. Message conversation — chat bubble sequencing and VO timing
20. Map route — labeled stops and path trace (geodata must be verified)
21. Case-file reveal — evidence thumbnails and highlighted redactions
22. Newspaper collage — cutout layers with depth and camera push
23. Audio waveform card — true audio-driven visualization
24. Photo documentary — restrained Ken Burns with subject-aware crop

## Product, social & branding
25. SaaS UI walkthrough — cursor, focus, zoom, callout
26. Device mockup — responsive device frame and screen transitions
27. Product feature carousel — feature panels with match-cut transitions
28. Logo sting — short identity reveal, no excessive distortion
29. Social hook — 1–3 second claim with supporting visual
30. Before/after — identical alignment and controlled reveal
31. 3D depth cards — subtle perspective and lighting consistency
32. End-screen CTA — clear hierarchy, no misleading fake buttons

## Template selection matrix
High information density → 09–16; personal narrative → 17–24; brand/product → 25–32; arguments/voiceover → 01–08.
