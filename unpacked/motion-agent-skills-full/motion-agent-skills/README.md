# Motion Agent Skills Pack

A practical, modular instruction pack for AI coding agents building motion graphics with Remotion and OpenFilm. This is a SKILL / prompt / code-example bundle, **not** a preinstalled library of 32 rendered templates.

## Quick start
1. Copy `AGENTS.md`, `skills/`, `docs/`, `templates/`, `schemas/` and `examples/` into your agent repository.
2. Point the agent to `AGENTS.md` and `docs/MASTER-PROMPT.md`.
3. Install an engine separately. For Remotion follow https://www.remotion.dev/docs ; for OpenFilm check Node >=22.2, ffmpeg and run `npx -y openfilm@latest`.
4. Give the agent a brief, VO, assets, target ratios and reference style.
5. Require a shot list before coding and a QA report before calling output final.

## Important distinction
This pack describes 32 motion design template concepts. They are specifications for future implementations, not bundled executable template components. The Remotion TSX files are small illustrative code examples, not a fully bootstrapped npm project. The OpenFilm HTML file is a shot illustration, not a complete film.html timeline.
