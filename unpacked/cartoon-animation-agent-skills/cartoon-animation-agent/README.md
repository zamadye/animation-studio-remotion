# Cartoon Animation Agent Skill Pack

Start with `AGENTS.md`, then `skills/cartoon-animation/SKILL.md`.

The sample `examples/CartoonGag.tsx` demonstrates deterministic frame-driven movement and vector character layers, **not** a complete finished production. Integrate `CartoonComposition` in a Remotion Root; add actual dialogue, SFX, assets, shot choreography and render QA before publishing.

The referenced YouTube video was not visually inspected; this pack is a general 2D cartoon-animation foundation, not a verified reconstruction.
